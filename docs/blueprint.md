# **App Name**: AutoPool

## Core Features:

- Car Listing: Allow rental agencies to register and list their available cars with relevant details (e.g., car model, year, rental price, location, availability).
- Car Search and Discovery: Enable users to search for available cars based on location, dates, price range, and car type. Display search results in a clear and user-friendly manner.
- Booking Request: Provide a booking system where users can select a car, specify rental dates, and submit a booking request to the rental agency.
- Car and Rental Agency Reviews: Enable users to review cars and rental agencies, leave comments, and rate their experience.
- Chat Options: Implement a chat feature allowing users and rental agencies to communicate directly regarding booking inquiries, car details, and other relevant information.

## Style Guidelines:

- Primary color: Blue (#3498db) to convey trust and reliability.
- Secondary color: Gray (#ecf0f1) for backgrounds and subtle elements.
- Accent: Green (#2ecc71) to indicate availability and positive actions.
- Clean and modern sans-serif fonts for readability and a professional look.
- Use clear and recognizable icons for navigation, car details, and booking options.
- Grid-based layout for car listings and search results to ensure a consistent and organized presentation.
- Subtle transitions and animations to enhance user experience, such as loading indicators and smooth scrolling.
